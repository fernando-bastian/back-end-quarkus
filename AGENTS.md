# convenções do projeto

- Mantenha o código simples e adequado a um projeto acadêmico em Java e Quarkus.
- Escreva mensagens de commit em português, em caixa baixa, curtas e naturais. Exemplo: `adiciona cadastro de contas`.
- Descreva o que mudou, sem frases genéricas ou formalidade desnecessária.
- Os commits devem usar somente a autoria de Fernando Bastian já configurada no Git, sem trailers de coautoria.
- Use comentários em português para explicar decisões que não ficam claras no código, especialmente segurança e concorrência.
- Evite comentários que apenas repetem o código. Não acrescente comentários decorativos ou documentação extensa sem necessidade.
- Em ajustes de estilo, preserve o comportamento e os testes existentes.
